# 学术写作提示词 · 理工科

**开题报告 / 学位论文 / 基金申请书** 的写作提示词。50 条主提示词（P0–P46），外加博士开题"研究背景与意义"的 7 条加更。默认学科：仪器科学、光电工程、计算机。

适用于任意对话模型（DeepSeek、Claude、GPT、Gemini 均可），不需要插件，复制即用。

---

## 为什么需要它

大模型不缺词汇量，缺的是约束。你给它一个题目，它只能给你"正确的废话"；你给它现象、矛盾、数据、你已有的结果，它才能写出评审看得懂的文字。

这个仓库做的就是把约束写进提示词：**只用手上的材料、不许编文献、一次只做一件事、写完自己挑错。**

它不负责替你想创新点，也不负责替你查文献。这两件事只能你自己做。

---

## 这个仓库是什么 / 不是什么

| 是                         | 不是                         |
| -------------------------- | ---------------------------- |
| 一组可复制的写作规格       | 一键生成整篇论文的"神器"     |
| 帮你把已有材料写成学术语言 | 帮你想出研究问题             |
| 帮你把草稿改得更有逻辑     | 帮你伪造数据、文献或实验结果 |
| 一套"写完怎么自查"的清单   | 查重或 AIGC 检测的规避工具   |

---

## 快速开始

1. **先贴底座**：把 [P0](#p0--学术合作者底座) 整段发给模型，定下"不编造、一次一件事"的规矩。
2. **让它先问你**：接 [P0.1](#p01--只提问模式)，把它需要而你没给的信息问出来，你逐条回答。
3. **按场景取一条**：写背景用 P6（硕士）或 P6D（博士），写引言用 P18，写立项依据用 P34。一次只写一节，写完再开下一节。

> 三十秒示例：把 P0 发过去 → 粘上你的题目和三段素材 → 说"用 P6D-3 写研究背景"。不要一次要全文。

---

## 十条硬规则

这些规则压过任何一条提示词里的示例，也压过模型"顺手帮你补全"的冲动。

1. **材料之外不补**：不补充具体文献、数据、政策文号、案例、实验结果。缺的写【待补】，举例写【示例，待核实】。
2. **不确定就说不确定**：并说明该去哪个库、用什么检索式核实。不把记忆里的论文写成已核实的文献。
3. **一次只做一件事**：不顺手重写全文，不擅自加观点。改结构、逻辑、语气，不改你的立场。
4. **数字只有一个来源**：你的"事实底稿"。摘要、正文、表格里的同一个数字必须一致。
5. **中文优先，术语中英并列**：首次出现写成"中文（English）"。写英文论文时直接写英文，不要先中后英。
6. **模板优先**：学校模板、期刊作者指南、当年《项目指南》里的章节名和字数，压过本文所有建议。
7. **改写要附说明**：不超过 5 条，说清动了哪里，不增加新事实。
8. **没有证据不写断言**："填补空白""国际领先""首次""具有重要的理论意义和现实意义"——这四类词，没有文献支撑就删掉。
9. **转述而非照搬**：引用观点用自己的话重述，保留限定条件，句末标 [n]；[n] 必须对得上你给的文献清单，没有清单就用【作者, 年份】，不编编号。
10. **合规优先**：基金申请书通常要求申请人本人撰写，AI 适合检索、整理、润色；论文投稿多数期刊要求披露 AI 使用。交付前以本校、本刊、当年指南为准。

## 一、通用底座

### P0 · 学术合作者底座

```text
你是我长期的学术写作合作者，不是代笔。你的职责是：把我模糊的想法逼成清晰的问题，把我的草稿改成符合【学科】规范的表达，并在逻辑、事实、引用上挑错。

硬性规则：
1. 我给你的材料之外，不补充任何具体文献、数据、政策、案例；确需举例时标注【示例，待核实】。
2. 不确定就直说"不确定"，并告诉我应该去哪里、用什么检索式核实。
3. 每次只执行我要求的那一项任务，不顺手重写全文，不擅自增加观点。
4. 我的观点优先。你要改的是结构、逻辑、语气，不是立场。
5. 中文输出；专业术语首次出现时保留英文原词，格式：中文（English）。

现在先复述你对任务的理解（不超过 3 句），然后问我 3 个最关键的问题，等我回答后再动笔。
```

### P0.1 · 只提问模式

```text
先不要写任何正文。围绕【我的题目/方向】，列出为了写好它你必须知道、但我还没告诉你的 12 个问题，按重要性排序，每个问题说明"为什么它会影响写法"。
我回答后你再开始。
```

> 写得空，多半不是文笔问题，是材料没给够。这一步能省掉后面大半的返工。

### P0.2 · 审稿人模式

```text
切换到审稿人模式。你是【期刊档次】的审稿人，方向是【】。
对下面这段文字，只做三件事：
1. 用一句话概括它实际说了什么（不是它想说什么）；
2. 指出 3 处逻辑跳跃或证据不足，引用原句；
3. 给出修改优先级：必须改 / 建议改 / 可不改。
不要替我重写。
```

### P0.3 · 引用核验模式

```text
下面是我文中的引用清单（作者 年份 期刊 标题）。逐条判断它是否可能真实存在，并说明判断依据。标注：高置信 / 存疑 / 高度疑似虚构。
对"存疑"和"疑似虚构"的，给出我应该在 PubMed / Web of Science / CNKI / Google Scholar 使用的检索式。
严禁替我补全作者、卷期、页码、DOI。
```

## 二、开题报告

### P1 · 选题收敛

```text
我的方向是【】。请用"现象—矛盾—空白—问题"四步帮我收敛，每步都要具体：

1. 现象：这个领域目前公认的 3 个重要现象或事实（只写你有把握的，标注置信度高中低）。
2. 矛盾：现有解释或方法在哪里互相打架、或解释不了哪类观测。
3. 空白：由此产生的空白，分成理论空白 / 方法空白 / 数据空白 / 应用空白，各举 1 例。
4. 问题：给出 5 个可操作的研究问题，每个一句话，必须含"研究对象 + 关键变量或机制 + 边界条件"。

然后对 5 个问题打分（1-5）：三年内可完成性、数据可得性、创新度、被同行抢先的风险、与我现有基础的匹配度。
最后推荐 1 个，并明确说明"为什么不选另外 4 个"。
```

### P2 · 研究问题拆解

```text
我的总目标是【】。请把它拆成 3-4 个子问题，要求：
- 每个子问题对应一个可交付的结果（论文/模型/数据集/结论），写出来；
- 子问题之间是递进关系，不是并列清单，请说明"前一个的结论如何成为后一个的输入"；
- 每个子问题给出 1 个可证伪的预期或假设；
- 标出哪个子问题失败会导致整个课题无法成立（关键路径）。
用表格输出。
```

### P3 · 文献矩阵（喂料式）

```text
我不需要你替我找文献。以下是我读过的文献要点（逐条粘贴：作者年份 / 研究问题 / 方法 / 样本或数据 / 核心结论 / 作者自述局限）。

请：
1. 按"学术争论"把它们组织成 3-5 个阵营，而不是按时间或作者罗列；
2. 输出对照表：文献 | 阵营 | 问题 | 方法 | 数据 | 结论 | 局限 | 与我的关系（支持/冲突/互补）；
3. 指出每个阵营的共同假设是什么，谁的证据更强，强在哪；
4. 找出所有文献共同没做的事，并判断这是"没人想到"还是"客观上做不了"；
5. 用 300 字写一段评述：先肯定进展，再指出分歧，最后落到我的问题上。

禁止添加清单之外的任何文献。
```

### P4 · 识别真正的空白

```text
基于上面的文献矩阵，给出 5 个候选研究空白，并逐个"压力测试"：
- 它是真空白，还是只是没人用某种方法做过（后者是集成，不是空白）？
- 如果它重要，为什么这几年没人做？（数据难得 / 技术不成熟 / 结论已隐含在别的文献里 / 其实做过了）
- 需要什么关键证据才能填补？
- 如果我现在做，最可能被审稿人用什么理由拒？
最后只保留 2 个能站住的，并给出对应的"一句话立项理由"。
```

### P5 · 开题报告目录设计

```text
我是【学校/学院】的【硕士/博士】研究生，题目暂定《【】》，学院模板要求如下：【粘贴模板结构或字数要求】。

第一步只做目录，不写正文。按模板逐节给出：
- 这一节要回答的核心问题（一句话）；
- 评委/导师最想看什么；
- 最常见的失分点；
- 建议字数；
- 我需要提前准备哪些材料（数据、图、文献）。

第二步：检查各节之间是否存在"研究内容—研究方法—预期成果"对不上的地方，列出来。
等我确认目录后，再逐节写正文。
```

### P6 · 研究背景与意义（硕士 / 默认 800 字）

```text
写开题报告的"研究背景与意义"，800 字，四段：
段1（150字）：从一个具体的现实问题或反常现象切入，不要用"随着……的快速发展"开头。
段2（250字）：这个问题为什么现在必须解决——政策、产业、健康、安全任一维度，用我提供的数据【粘贴数据】；我没给的数据标【待补】。
段3（250字）：现有做法做到哪一步、卡在哪，引出本研究的位置。
段4（150字）：理论意义 + 实践意义各一句，必须具体到"为谁解决什么"，禁止"具有重要的理论意义和现实意义"。

要求：每段第一句是论点句；全文不出现"填补空白""国际领先""首次"。
```

> 博士开题不要用这一条，改用下面的 P6D。

### P7 · 国内外研究现状（CARS 四层）

```text
按 Swales 的 CARS 模型写"国内外研究现状"，1500 字，四层：
1. 确立领域：该问题在【学科】中的位置，近 5 年为何升温（只写趋势，不写具体文献）。
2. 划分阵营：把已有工作分成 3 条路线，每条路线 1 段，结构为"代表做法 → 解决了什么 → 代价是什么"。
3. 指出缺口：用"然而/但是"转折，落到 2 个具体缺口，每个缺口要能被我的研究内容直接对应。
4. 占据位置：一句话说明本研究如何补这两个缺口（不展开方法）。

规则：每段一个论点；路线之间要有比较，不能各说各话；引用处写成【作者, 年份】占位，由我后补真实文献。
```

### P8 · 研究内容、重点与难点

```text
基于我的题目《【】》和上面确定的研究问题，写"研究内容"，要求：
1. 总起段：一句话说清整个课题在做什么，100 字以内；
2. 分 3 个研究内容，每块 250 字，内部按"要解决什么 → 具体做什么 → 产出什么"组织；
3. 三块之间必须是递进（内容2 用内容1 的结果），并显式写出衔接句；
4. 单列"研究重点"2 条、"研究难点"2 条，难点必须写出"难在哪、我打算怎么绕过去"。

禁止把研究内容写成方法罗列或时间计划。
```

### P9 · 研究方法与技术路线

```text
为上述 3 个研究内容设计研究方法与技术路线：
1. 每个研究内容配 1-2 个方法，写清：方法名、输入、关键步骤、输出、为什么这个方法适合这个问题（而不是"该方法被广泛使用"）。
2. 给出技术路线文字描述：从数据/样本 → 处理 → 分析/建模 → 验证 → 结论，每一步标注对应研究内容编号。
3. 用 Mermaid 画流程图（flowchart TD），节点不超过 20 个，关键判断用菱形。
4. 列出 3 个可能失败的技术环节和备选方案。
形式：先文字，后代码块。
```

### P10 · 创新点

```text
从我的研究内容中提炼 3 条创新点，每条 120 字，严格按四要素写：
【类型：理论/方法/视角/数据/集成】+【现有做法及其局限】+【我的做法及为何能突破】+【突破后的意义】。
要求：每条注明对应的研究内容编号；删掉所有形容词；"首次将 A 用于 B"这类表述必须补充"为什么这个迁移不平凡"。
```

### P11 · 进度安排与预期成果

```text
按【3 年/2 年】制定进度表，按学期或季度分 6-8 个阶段，表头：时间 | 任务 | 对应研究内容 | 里程碑成果 | 风险。
要求：文献调研不超过总时长的 1/5；预留 3 个月用于补实验和写作；每个阶段都有可检查的产出物。
另附预期成果：论文【】篇（注明目标期刊层次）、专利/软著【】、数据集/模型【】、毕业要求如何对应。
```

### P12 · 开题答辩：PPT 与追问预演

```text
我要做开题答辩，15 分钟。请：
1. 给出 12 页 PPT 大纲，每页：标题 + 3 个要点 + 建议配图类型 + 讲述时长；
2. 扮演 5 位评委（2 位小同行、1 位方法学专家、1 位跨学科、1 位严格管进度的），各提 3 个最可能问的问题，按"杀伤力"排序；
3. 对最狠的 5 个问题，给出 3 句话以内的回答要点（先承认边界，再给方案，最后给时间点）。
```

### P13 · 开题报告整体体检

```text
通读我的开题报告（粘贴全文），按下面清单逐项打勾或打叉，并给出修改建议（每条不超过 2 句）：
□ 题目是否指向一个具体问题，而非一个领域
□ 研究问题是否只有 1 个主线，而不是 4 个并列方向
□ 研究内容、方法、预期成果是否一一对应（列出对应表）
□ 每个创新点是否有"现状—差异"的对比
□ 技术路线是否能看出先后依赖
□ 进度安排是否与工作量匹配
□ 参考文献近 5 年占比是否 ≥ 50%
□ 全文是否存在"具有重要意义"类空话（统计出现次数）
最后给一个总体判断：可以开题 / 小修后开题 / 需重写某节。
```

## 三、博士开题加更：研究背景与意义

博士这一节比硕士多一道关：**证明这个缺口卡住了领域，而不只是"还没人做"**。硕士版 P6 的 800 字四段撑不住，改用下面七条。

三条验收标准：

1. 问题真实存在——有现象、数据或文献，不是"我觉得有意思"。
2. 缺口是卡住了，不是没人做——没人做是减分项，现有路线做不了或做偏了才是加分项。
3. 意义配得上博士体量——应用验证不够，要有理论或方法上的推进。

背景与意义合计按 2500 字掌握（有模板时按模板）。背景回答"问题从哪来"，意义回答"解决之后改变什么"；能分开就分开写。

### P6D-1 · 先问八个问题

```text
先不要写正文。围绕我的博士论文题目《【题目】》，只就"研究背景与意义"这一节，问我 8 个必须回答的问题，按重要性排序，每个问题说明"答案会怎样改变这一节的写法"。

必须覆盖：该领域近五年公认的进展、已知的反常或失效案例、谁在关心这个问题（学界/产业/政策，理工课题再加工程应用）、如果不解决五年后会怎样、我的前期工作处在哪一步。

我回答后你再动笔。
```

### P6D-2 · 段落任务书

```text
不要写正文。给我一份"研究背景与意义"的段落任务书，总字数【2500】，分 5 段。每段列出：段首句（写成完整句子）、这一段要完成的论证任务、需要哪类证据或文献、建议字数。

硬约束：5 段连起来必须回答三个问题——为什么这个问题存在、为什么现在必须解决、为什么由我来做。如果某一段删掉后这三个问题仍成立，标出来，我砍掉它。
```

### P6D-3 · 把综述写成论证

```text
你是【学科】方向的博士开题评审专家。素材如下：
研究现象：【】
现有解释或做法：【】
我注意到的矛盾/反常：【】
我的研究问题：【】

请写"研究背景"，要求是论证，不是文献综述：
段1（200字）：用一个具体事实、数据或案例开篇，最后一句点出"为什么这件事现在必须回答"。
段2（450字）：已有研究做到哪一步——按 2-3 条路线，每条按"代表做法→解决了什么→付出了什么代价/边界在哪"写。
段3（450字）：这些路线共同回避或解释不了什么。要说明它是"卡住了"，不是"还没人做"。
段4（200字）：我的问题如何从这个缺口里长出来，一句话收住。

规则：每段首句是论点句；不出现"随着……的发展""具有重要的理论意义"；文献位置一律写【ref】，不要编造作者和年份；拿不准的地方标【待核】。
```

### P6D-4 · 意义三层 + 所以呢

```text
写"研究意义"，分三层，每层 150-200 字：
1. 理论意义：对哪个理论、概念或机制构成修正、补充还是挑战？说清"修正了什么、往哪个方向修正"。
2. 方法意义：提供了什么新工具、新数据或新设计？谁可以直接复用、复用在什么场景？
3. 实践意义：谁会用、用来做什么决定、可能改变什么？必须给一个具体场景，不要给一个群体名词。

写完后，对每条意义追问一次"所以呢？"，把追问出来的那一层补进去，删掉被追问穿的句子。

禁止："具有重要的理论意义和实践价值""为……提供参考""填补了空白"。
```

> 仪器、光电、计算机的理论意义要落到测量原理、误差关系、成像模型或算法假设上，不能只写"提升了精度"。

### P6D-5 · 两版改写（默认不做）

```text
把上面写好的"背景与意义"改写成【人文社科 / 理工医】版本：
- 人文社科版：以理论争论或现实问题切入，突出概念界定与解释框架的冲突，意义落在"对既有解释的修正"和"对政策/实践的启示"，允许出现田野、文本、案例。
- 理工医版：以技术瓶颈或工程需求切入，突出指标、条件、适用边界，意义落在"机制揭示""方法可用性""性能提升幅度"，必须给量化对照。

输出改写稿，并列出两版在"证据类型、论证顺序、意义落点"上的差异表。
```

> 量化对照只用你给的数字。没有数字就写"幅度【待补】"，不要配一个示例百分比。

### P6D-6 · 写完自检

```text
以博士开题评审专家身份审我这段"研究背景与意义"（粘贴）：
1. 用一句话说出你认为我的研究问题是什么——如果说不出来，说明我没写清；
2. 统计"背景铺陈"与"问题论证"的字数比，超过 2:1 就提示我；
3. 找出 3 句"正确但无用"的话（换个题目也成立的句子），逐句引用；
4. 找出 2 处"意义悬空"（结论大于证据）；
5. 提 3 个答辩最可能被追问的问题，并判断我现在的文本能否回答。
```

### P6D-7 · 去掉综述味

```text
把下面这段"综述式背景"改成"论证式背景"，只做四件事：
1. 把"XX 研究表明……""XX 发现……"的并列堆叠，改成"关于 X，存在两种对立解释：……"；
2. 每处引用后补一句"这对我意味着什么"；
3. 把"尚未见报道"改成"现有工作在【条件】下失效，因为……"；
4. 段尾加一句指向我研究问题的过渡。
保留我的文献和数据，不新增任何事实。
```

### 三个最常见的失分点

| 症状     | 表现                                         | 改法                                   |
| -------- | -------------------------------------------- | -------------------------------------- |
| 综述化   | 三段都在说"谁做了什么"，没有一句"所以卡在哪" | 每条路线以"代价/边界"收尾              |
| 意义悬空 | "为 XX 提供理论依据"，但没有任何理论被修正   | 用 P6D-4 的"所以呢"追问，问穿就删      |
| 头重脚轻 | 背景很长，研究问题只有一两句                 | 背景:问题控制在 2:1 以内，问题单独成段 |

## 四、论文

### P14 · 投稿定位

```text
我的论文核心是【一句话】，主要贡献是【】，数据规模/实验条件是【】。
请推荐 5 个目标期刊（英文按 JCR 分区，中文按 CSSCI/CSCD），对每个给出：
- 为什么匹配（近两年是否发过类似主题，用你的知识判断并标注不确定性）；
- 审稿周期与难度的通常情况；
- 我的工作在该刊属于"够得着 / 偏弱 / 可冲"；
- 如果被拒，下一个去哪。
按"投稿顺序"排序，并说明第一站选它的理由。
```

### P15 · 一句话贡献 + 故事线

```text
帮我把这篇论文压缩成：
1. 一句话贡献（≤25 字，含"在什么条件下，用什么方法，解决了什么，比现有好多少"）；
2. 三条支撑证据（每条对应一组结果）；
3. 一条故事线：读者已知什么 → 卡在哪 → 我们做了什么 → 所以现在能怎样。
要求：如果某条证据撑不起这句话，直接指出来。
```

### P16 · 标题

```text
基于摘要【粘贴】，给 8 个标题，分三组：
A 偏机制/发现（陈述结论式）
B 偏方法（点名方法名 + 应用对象）
C 偏问题（提出疑问或对比式）
要求：≤20 词/≤25 字；含 2 个可检索关键词；不用"研究""初探""浅析"；不用冒号堆叠；每个标题后注明适合的期刊类型。
```

### P17 · 摘要

```text
基于以下信息写摘要：【研究问题、方法、主要结果（含数字）、结论】。
先写 250 词英文结构化摘要（背景 1 句 / 问题 1 句 / 方法 2 句 / 结果 2-3 句必须含具体数值与对照 / 结论 1 句含意义），再给 5 句压缩版（用于投稿系统），再给中文版。
规则：结果句必须有数字和比较对象；"显著"仅在给出统计检验时使用；不出现"首次""填补空白"；不出现正文没有的结论。
```

### P18 · Introduction（CARS 四段）

```text
按 Swales CARS 模型写 Introduction，四段，共 700-900 词：
段1 确立领域：从宏观意义收到一个具体现象，最后一句点明该现象为何关键。
段2 文献评述：按 3 个阵营评述，每句带【ref】占位，要有褒有贬，不是流水账。
段3 指出缺口：现有工作在什么条件下失效、忽略了什么变量、数据只覆盖了什么范围——要具体到可验证。
段4 本文工作：我们提出【】，在【】上验证，贡献 3 点，每点一句话。

校验：段3 的每个缺口，必须能被段4 的某条贡献闭合；不提前剧透结果数字；段2 不出现"大量研究表明"。
```

### P19 · Related Work

```text
写 Related Work，按"问题"而不是"论文"组织：
1. 分成 2-3 个与我的贡献直接相关的研究线；
2. 每条线：这类方法的核心假设 → 代表工作 → 在什么情况下失效；
3. 每条线结尾一句"与本文的区别"，区别要具体到设定、数据、评价方式；
4. 最后一段用 2 句话总结本文与最近工作的差异。
禁止：逐篇罗列、只写优点、把 Introduction 再说一遍。
```

### P20 · Methods（可复现性）

```text
把我的方法部分改写成可复现的写法，按顺序覆盖：
研究设计 / 数据来源与纳入排除标准 / 变量定义与测量 / 模型或实验设置（含超参数与随机种子策略）/ 评价指标 / 统计方法 / 伦理与知情同意（如适用）/ 代码与数据可获得性。
要求：每个"我们做了 X"后面补一句"具体怎么做的"；凡是无法复现的表述（如"进行了充分训练"）单列出来，让我补。
```

### P21 · Results（图表叙事）

```text
我的主要结果是：【按顺序列结果与数字】。
请把 Results 写成"每个图/表一段"的结构，每段四句：
① 这段回答哪个问题；② 看到了什么（数值、趋势、对照）；③ 这个结果说明什么（克制，不解释机制）；④ 引向下一段。
要求：不在 Results 里讨论机制；每个数字都给对照（基线/对照组/文献值）；指出哪些结果目前证据偏弱，需要补什么实验。
```

### P22 · Discussion

```text
写 Discussion，五段：
1. 重述主要发现（不重复结果数字，只给结论）；
2. 机制解释：为什么会这样，给出 2 种可能解释并说明哪种更可能、如何区分；
3. 与已有研究对比：一致在哪、不一致在哪、不一致的可能原因；
4. 局限：3 条，按严重程度排序，每条附"对结论的影响范围"；
5. 意义与展望：对理论/实践各一句，展望要具体到下一步做什么。
规则：不引入 Results 里没有的新结果；局限不写成"样本量有限"这种套话，要写清"因此结论只适用于……"。
```

### P23 · Conclusion

```text
写 Conclusion，200 字以内，回答三个问题：我们做了什么、发现了什么、这意味着什么。
不重复摘要原句；不出现新数据；不出现"综上所述"；最后一句给一个可被引用的判断句。
```

### P24 · 段落级改写

```text
改写下面这段，只做四件事：
1. 把第一句改成明确的论点句（这段到底想说什么）；
2. 句子之间补逻辑连接（因果/转折/递进），删掉"此外""同时"这类假连接；
3. 把名词化表达还原成动词（"对数据进行了分析"→"分析了数据"）；
4. 拆开超过 45 字的长句。
保留我的原意、术语和数据，不增加新内容。输出：改写稿 + 3 条改动说明。
```

### P25 · 中译英（学术语体）

```text
把下面这段中文译成学术英文，要求：

- 术语按【学科】惯用译法，首次出现给缩写；
- 不逐字直译，按英文信息结构重排（先结论后条件）；
- 句长 15-25 词为主，避免连续三个长句；
- 保留所有数字、单位、引用标记原样。
```

### P26 · 英译中

### P27 · 审稿意见回复

```text
你是我的共同作者，熟悉这篇论文。以下是审稿意见【粘贴】和我的论文摘要【粘贴】。
逐条回复，格式固定：
【审稿意见原文】→【立场：同意 / 部分同意 / 不同意】→【回应 2-4 句】→【修改位置：第 X 页第 Y 行】→【修改后的文字】。
```

### P29 · 表达自然化（合规版）

> 说明：AI 检测器本身不可靠，且多数学术机构禁止的是"代写"，不是"润色"。这一条用来让表达回到你自己的语感，不用于规避学术不端审查。

```text
改写下面这段，目标：读起来像同一个研究者写的，而不是模板生成的。
1. 打散过于工整的排比和"首先/其次/最后"的三段式；
2. 句长参差：两个短句 + 一个长句交替；
3. 加入具体限定（"在 X 类样本中""当 Y 超过阈值时"），删掉无信息的限定（"在一定程度上""某种程度上"）；
4. 把"具有重要意义""值得深入探讨"替换成具体判断；
5. 保留我的用词习惯：我喜欢用【列举你的高频词】。
不增加新事实。输出改写稿 + 改动说明（≤5 条）。
```

```text
输出问题清单：位置 | 问题 | 建议改法。
```

### P31 · 科学问题凝练

### P32 · 题目打磨

```text

2. 给 6 个改法：3 个更聚焦机制，3 个更聚焦方法与应用；

4. 推荐 1 个，说明理由。
```

### P33 · 摘要（400 字）

```text
写项目摘要，400 字，五句结构：
① 针对【什么现象/需求】，目前【什么瓶颈】；
② 本项目拟以【对象】为研究对象，围绕【科学问题】；
③ 采用【方法1+方法2】，开展【3 项研究内容】；
④ 预期揭示【机制/规律】，建立【模型/方法】，实现【指标提升】；
⑤ 研究成果将为【领域】提供【理论依据/技术支撑】。

要求：出现 3 个以上具体科学术语；不出现"国际领先""填补空白"；不出现"本项目组认为"；数字指标必须我能做到。
```

### P34 · 立项依据（倒金字塔）

```text
写"立项依据"，2500 字，五段：
段1（300 字，最重要）：一句话点出科学问题 + 与现有研究的本质区别 + 突破后可能改变什么。禁止以"随着……的发展"开头。这一段要能独立成文。
段2（500 字）：宏观需求，政策/产业/健康/安全，用我提供的数据【粘贴】，缺的标【待补数据】。
段3（800 字）：国内外现状，按 3 条理论或技术路线评述，每条结尾一句指出局限。
段4（500 字）：凝练 2 个具体空白，编号与我的研究内容一一对应。
段5（300 字）：本项目思路一句话 + 预期突破 2 条。

要求：每段首句是论点句；不出现"具有重要意义""国际领先""首次"；每条"现状"都要能追到具体文献（我用【ref】占位后补）。
```

### P35 · 研究目标与研究内容

```text
基于上面的科学问题，写"研究目标"与"研究内容"：
1. 研究目标：总目标 1 句（≤60 字，含"揭示/建立/阐明"+对象+预期），分目标 3 条，每条对应 1 项研究内容。
2. 研究内容：总起段（100 字）+ 3 个专题，每个专题 300 字，内部再分 2-3 个孙内容；
   每个孙内容按"复杂问题 → 现实困境 → 现有研究局限 → 本质矛盾 → 突破需求 → 问题落点"六步写。
3. 输出一张闭环表：研究目标 | 研究内容 | 关键科学问题 | 预期成果，检查是否一一对应。

禁止：研究内容是方法的罗列；专题之间是并列而非递进。
```

### P36 · 关键科学问题

```text
从上述研究内容中提炼 2 个"拟解决的关键科学问题"，要求：
- 每个 ≤50 字，是"机制/规律/耦合/判据"类问题，不是"开发一套系统"；
- 指出它为什么"关键"（不解决会导致哪部分研究失效）；
- 说明它与研究内容的对应关系；
- 说明现有理论为什么回答不了。
再检查：这两个问题是否其实是同一个问题的两种说法。
```

### P37 · 研究方案与技术路线

```text
写"研究方案"，对应 3 项研究内容，每项包含：研究思路（1 句）→ 具体方案（分步骤）→ 关键技术（点名，说明难点）→ 验证方式（怎么算成功）。
再给技术路线：
1. 文字版，标明阶段、输入、输出、与内容的对应；
2. Mermaid flowchart（TD），节点 ≤18 个，含 2 个判断节点；
3. 指出 3 个最可能卡住的环节及备选方案。
要求：方案要具体到"用什么数据、什么设备、什么模型、什么指标"，不写"拟采用先进方法"。
```

### P38 · 特色与创新

```text
提炼 3 条"特色与创新"，每条 120 字，格式：
【类型：理论/方法/视角/数据/集成】+【现有做法及局限】+【本项目做法及为何能突破】+【突破后的意义】。
规则：每条对应具体研究内容；不写"首次""领先"；集成式创新必须说明"为什么这个集成不平凡"；删掉所有形容词只留事实。
```

### P39 · 可行性分析

```text
写"可行性分析"，四个维度各 150 字：
1. 理论可行：已有理论/前期结果支持；
2. 方法可行：关键方法在本领域已被验证，或我们已掌握；
3. 条件可行：数据、设备、平台、样本来源；
4. 队伍可行：申请人及团队的分工与互补。
要求：每条给一个"证据"（前期论文/预实验/合作单位），不能用"团队实力雄厚"代替证据。
```

### P40 · 研究基础与工作条件

```text
我有以下成果：【列 5 篇代表作：题目/期刊/年份/作者位次/主要结论/与本题关系】。
请：
1. 判断这 5 篇是否构成"机制发现 → 验证 → 拓展"的链条，若不成链，指出缺哪一环；
2. 按"与本题相关性"重排，给出取舍建议；
3. 为每篇写 2 句"个人贡献声明"（负责什么、约占工作量多少），避免夸大；
4. 写"工作条件"300 字：平台、设备、数据、合作，只写真的有的。
```

### P41 · 年度计划与预期成果

```text
制定【3 年】年度计划，逐年列出：研究内容 | 关键节点 | 可检查产出（论文/专利/数据集/报告）。
再写预期成果：论文【】篇（注明层次）、专利/软著【】项、人才培养【】、成果形式【】。
要求：年度计划与资金使用节奏匹配；不出现"发表高水平论文若干篇"这类不可检查的表述。
```

### P42 · 五人模拟评审

```text
你现在是 5 位评审专家，独立评审下面这份本子（粘贴全文）：
A 小同行（同方向，最懂细节）
B 小同行（相邻方向，懂方法不懂对象）
C 大同行（同领域，不懂细节）
D 方法学/统计学专家
E 严格型评委（专挑可行性、工作量、创新性）

每人输出：
- 总体评价（2 句）
- 最强的 2 点
- 最可能被攻击的 3 点（必须引用原文段落）
- 建议：优先资助 / 可资助 / 不资助
- 一句话理由

最后汇总：① 五人共识的弱点；② 如果只能改 3 处，改哪 3 处收益最大（按投入产出排序）。
```

### P43 · 毙稿自查

```text
按下面清单检查我的本子，逐项给"是/否/部分"，并指出具体段落：
1. 前 500 字是否说清了科学问题和原创点
2. 题目、摘要、目标、内容、创新点是否指向同一个问题
3. 研究内容是否超过 3 块、是否平行发散
4. 关键科学问题是否其实是技术问题
5. 创新点是否有文献对比支撑
6. 技术路线是否只是研究内容的重复
7. 工作量与经费、期限是否匹配（是否 3 年做不完或不够做）
8. 预期成果是否可检查
9. 是否存在"国际领先/填补空白/首次"等无证据断言（统计次数）
10. 参考文献是否近 5 年为主、是否含该领域必引的经典
输出：总体风险等级（高/中/低）+ 必须改的 5 条。
```

### P44 · 国社科 / 教育部项目适配

```text
把上述内容改写为国社科（或教育部人文社科）风格：
1. 研究价值部分增加"学科建设价值"与"服务决策"维度，语言更强调现实关切；
2. 研究内容改为"总体框架 + 重点难点 + 主要目标"，突出问题导向而非技术路线；
3. 增加"研究思路与方法"中的田野/文本/案例说明；
4. 预期成果以专著、决策咨询报告、论文并重；
5. 删掉工程化表述（"研制""系统开发"），换成"建构""阐释""考察"。
输出改写后的对应章节，并列出两版差异表。
```

### P45 · 事实与数据核查

```text
下面这段里有 N 个事实性断言（数字、政策、时间、比例）。请逐条拆出来，做成表：
```

### P46 · 学术诚信边界

```text
我要写【论文/开题报告/基金申请书】。请先告诉我：
1. 这类材料通常允许 AI 辅助到什么程度（检索、提纲、润色、翻译、成段生成分别怎么看）；
2. 哪些做法属于高风险（代写、伪造数据、伪造引用、规避检测）；
3. 如果我使用了 AI 辅助，通常应在哪里、如何声明；
4. 你建议我保留什么样的过程记录以备核查。
只讲通用惯例，并提醒我以本校/本刊/本项目指南为准。
```

> 现实提醒：基金申请书一般要求"由申请人本人撰写"，AI 只能用于检索、整理、润色；论文投稿多数期刊要求披露 AI 使用。别把"能生成"当成"可以交"。

## 七、把它们串成流程

单条提示词只能救一段话，稳定的产出靠流程：

```text
① 素材 → ② 提问 → ③ 骨架 → ④ 逐节写 → ⑤ 挑错 → ⑥ 重写 → ⑦ 核查
```

| 阶段     | 用哪条                                     | 产出                   |
| -------- | ------------------------------------------ | ---------------------- |
| ① 素材   | 自己整理文献矩阵、数据表、预实验、政策原文 | 一份"事实底稿"         |
| ② 提问   | P0.1 / P6D-1                               | 待答问题清单           |
| ③ 骨架   | P5 / P15 / P35                             | 目录或故事线，先审后写 |
| ④ 逐节写 | P6-P11 / P17-P23 / P33-P41                 | 一节一个对话           |
| ⑤ 挑错   | P0.2 / P13 / P42 / P43                     | 问题清单               |
| ⑥ 重写   | P24 / P29                                  | 改后稿 + 改动说明      |
| ⑦ 核查   | P0.3 / P30 / P45 式清单                    | 引用核验表、一致性清单 |

三条经验：

- 新章节开新对话。一个对话里堆三万字，模型会忘掉前面的约束。
- 每次要"改动说明"。你才知道它动了什么，也方便回退。
- 数字只从事实底稿来，不从模型嘴里来。

## 八、常见问题

**Q：为什么不让模型直接帮我找文献？**
因为它会编。作者、年份、期刊、DOI 都可能看着很像真的。正确做法是 P3：你读完文献，把要点喂进去，让它帮你组织论证。

**Q：生成的字数总是不对。**
先让它出骨架（P5 / P6D-2），确认段落数和每段任务，再让它按段写。直接要"2500 字"它只会灌水。

**Q：博士和硕士的"研究背景与意义"差在哪？**
硕士版（P6）证明"这个题值得做"；博士版（P6D）还要证明"这个缺口卡住了领域，别人做不了或做偏了"。评审看的是后者。

**Q：这套东西能用于人文社科吗？**
默认按理工科写（仪器、光电、计算机）。人文社科可以用 P44 改写论证方式和意义落点，但证据类型不同（田野、文本、案例），不要硬套指标和误差。

**Q：写出来的东西能直接交吗？**
不能。基金申请书一般要求申请人本人撰写，论文多数期刊要求披露 AI 使用。它给的是草稿和结构，观点、数据、判断必须是你自己的。

**Q：会被查重或 AIGC 检测抓到吗？**
这类检测本身不可靠，也不该成为写作目标。P29 的作用是让你的表达回到自己的语感，不是绕过审查。真正降低风险的是：用自己的话重述、标注可核验的引用、保留过程记录。

## 九、学术诚信

- **文献**：不编造，不"顺手补全"作者、卷期、页码、DOI。拿不准就标【待核】。
- **数据**：不生成、不修饰、不外推。缺失就写缺失。
- **引用**：观点来自谁，标到谁；转述要保留限定条件，不能把"在 X 条件下成立"改成"普遍成立"。
- **AI 使用**：按学校、期刊、基金委的要求披露；保留提示词与修改记录，以备核查。

这个仓库提供的是写作结构和表达约束，不提供观点、数据或创新点。
