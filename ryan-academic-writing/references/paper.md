# 论文写作

整篇论文且故事线未确认时，只做 P15，然后停。点名某一节时只做对应条目。P14 的期刊匹配必须标注不确定性，不把未检索的“近两年发过”写成事实。P27 只在用户给出审稿意见时使用；不同意的意见不承诺做不了的实验。P29 只降低模板腔，不针对检测器。 动笔前按 references/stem-domains.md 判断贡献类型；没有用户给的基线数字，不要写显著优于。

## 4. 论文写作

### P14 · 投稿定位

```text
我的论文核心是【一句话】，主要贡献是【】，数据规模/实验条件是【】。
请推荐 5 个目标期刊（英文按 JCR 分区，中文按 CSSCI/CSCD），对每个给出：
- 为什么匹配（近两年是否发过类似主题，用你的知识判断并标注不确定性）；
- 审稿周期与难度的通常情况；
- 我的工作在该刊属于"够得着 / 偏弱 / 可冲"；
- 如果被拒，下一个去哪。
按"投稿顺序"排序，并说明第一站选它的理由。
```

### P15 · 一句话贡献 + 故事线

```text
帮我把这篇论文压缩成：
1. 一句话贡献（≤25 字，含"在什么条件下，用什么方法，解决了什么，比现有好多少"）；
2. 三条支撑证据（每条对应一组结果）；
3. 一条故事线：读者已知什么 → 卡在哪 → 我们做了什么 → 所以现在能怎样。
要求：如果某条证据撑不起这句话，直接指出来。
```

### P16 · 标题

```text
基于摘要【粘贴】，给 8 个标题，分三组：
A 偏机制/发现（陈述结论式）
B 偏方法（点名方法名 + 应用对象）
C 偏问题（提出疑问或对比式）
要求：≤20 词/≤25 字；含 2 个可检索关键词；不用"研究""初探""浅析"；不用冒号堆叠；每个标题后注明适合的期刊类型。
```

### P17 · 摘要

```text
基于以下信息写摘要：【研究问题、方法、主要结果（含数字）、结论】。
先写 250 词英文结构化摘要（背景 1 句 / 问题 1 句 / 方法 2 句 / 结果 2-3 句必须含具体数值与对照 / 结论 1 句含意义），再给 5 句压缩版（用于投稿系统），再给中文版。
规则：结果句必须有数字和比较对象；"显著"仅在给出统计检验时使用；不出现"首次""填补空白"；不出现正文没有的结论。
```

### P18 · Introduction（CARS 四段式）

```text
按 Swales CARS 模型写 Introduction，四段，共 700-900 词：
段1 确立领域：从宏观意义收到一个具体现象，最后一句点明该现象为何关键。
段2 文献评述：按 3 个阵营评述，每句带【ref】占位，要有褒有贬，不是流水账。
段3 指出缺口：现有工作在什么条件下失效、忽略了什么变量、数据只覆盖了什么范围——要具体到可验证。
段4 本文工作：我们提出【】，在【】上验证，贡献 3 点，每点一句话。

校验：段3 的每个缺口，必须能被段4 的某条贡献闭合；不提前剧透结果数字；段2 不出现"大量研究表明"。
```

### P19 · Related Work

```text
写 Related Work，按"问题"而不是"论文"组织：
1. 分成 2-3 个与我的贡献直接相关的研究线；
2. 每条线：这类方法的核心假设 → 代表工作 → 在什么情况下失效；
3. 每条线结尾一句"与本文的区别"，区别要具体到设定、数据、评价方式；
4. 最后一段用 2 句话总结本文与最近工作的差异。
禁止：逐篇罗列、只写优点、把 Introduction 再说一遍。
```

### P20 · Methods（可复现性）

```text
把我的方法部分改写成可复现的写法，按顺序覆盖：
研究设计 / 数据来源与纳入排除标准 / 变量定义与测量 / 模型或实验设置（含超参数与随机种子策略）/ 评价指标 / 统计方法 / 伦理与知情同意（如适用）/ 代码与数据可获得性。
要求：每个"我们做了 X"后面补一句"具体怎么做的"；凡是无法复现的表述（如"进行了充分训练"）标红列出，让我补。
```

### P21 · Results（图表叙事）

```text
我的主要结果是：【按顺序列结果与数字】。
请把 Results 写成"每个图/表一段"的结构，每段四句：
① 这段回答哪个问题；② 看到了什么（数值、趋势、对照）；③ 这个结果说明什么（克制，不解释机制）；④ 引向下一段。
要求：不在 Results 里讨论机制；每个数字都给对照（基线/对照组/文献值）；指出哪些结果目前证据偏弱，需要补什么实验。
```

### P22 · Discussion

```text
写 Discussion，五段：
1. 重述主要发现（不重复结果数字，只给结论）；
2. 机制解释：为什么会这样，给出 2 种可能解释并说明哪种更可能、如何区分；
3. 与已有研究对比：一致在哪、不一致在哪、不一致的可能原因；
4. 局限：3 条，按严重程度排序，每条附"对结论的影响范围"；
5. 意义与展望：对理论/实践各一句，展望要具体到下一步做什么。
规则：不引入 Results 里没有的新结果；局限不写成"样本量有限"这种套话，要写清"因此结论只适用于……"。
```

### P23 · Conclusion

```text
写 Conclusion，200 字以内，回答三个问题：我们做了什么、发现了什么、这意味着什么。
不重复摘要原句；不出现新数据；不出现"综上所述"；最后一句给一个可被引用的判断句。
```

### P24 · 段落级改写

```text
改写下面这段，只做四件事：
1. 把第一句改成明确的论点句（这段到底想说什么）；
2. 句子之间补逻辑连接（因果/转折/递进），删掉"此外""同时"这类假连接；
3. 把名词化表达还原成动词（"对数据进行了分析"→"分析了数据"）；
4. 拆开超过 45 字的长句。
保留我的原意、术语和数据，不增加新内容。输出：改写稿 + 3 条改动说明。
```

### P25 · 中译英（学术语体）

```text
把下面这段中文译成学术英文，要求：
- 用主动语态为主，方法部分可用被动；
- 术语按【学科】惯用译法，首次出现给缩写；
- 不逐字直译，按英文信息结构重排（先结论后条件）；
- 句长 15-25 词为主，避免连续三个长句；
- 保留所有数字、单位、引用标记原样。
输出：译文 + 3 个我不确定的地道表达（附备选）。
```

### P26 · 英译中

```text
把下面这段英文译成中文，要求：术语用学界通用译名（首次出现附英文）；长句拆分但不丢限定条件；保留引用标记；不要意译成"科普腔"。
译完后单列"我不确定的 3 处译法"。
```

### P27 · 审稿意见回复（Rebuttal）

```text
你是我的共同作者，熟悉这篇论文。以下是审稿意见【粘贴】和我的论文摘要【粘贴】。
逐条回复，格式固定：
【审稿意见原文】→【立场：同意 / 部分同意 / 不同意】→【回应 2-4 句】→【修改位置：第 X 页第 Y 行】→【修改后的文字】。

规则：
- 同意的，直接给出改后的句子，不要只说"我们已修改"；
- 不同意的，先准确复述对方逻辑，再给证据或反例，语气克制；
- 不承诺做不了的实验，改为"我们在局限中说明"；
- 每条不超过 150 字；
最后附一张"修改清单"表：意见编号 | 类型 | 是否修改 | 位置。
```

### P28 · Cover Letter

```text
写投稿信，300 词以内，五句结构：
① 投稿期刊与文章类型；② 一句话贡献；③ 为什么适合该刊（读者群/近期相关论文）；④ 原创性与未一稿多投声明；⑤ 通讯作者信息与推荐审稿人（可选）。
不要复述摘要；不要用"我们相信本文会引起广泛兴趣"这类空话。
```

### P29 · 降低"AI 味"（合规版）

> 说明：AI 检测器本身不可靠，且多数学术机构禁止的是"代写"，不是"润色"。以下提示词用于让你的表达更像本人写的，不用于规避学术不端审查。

```text
改写下面这段，目标：读起来像同一个研究者写的，而不是模板生成的。
1. 打散过于工整的排比和"首先/其次/最后"的三段式；
2. 句长参差：两个短句 + 一个长句交替；
3. 加入具体限定（"在 X 类样本中""当 Y 超过阈值时"），删掉无信息的限定（"在一定程度上""某种程度上"）；
4. 把"具有重要意义""值得深入探讨"替换成具体判断；
5. 保留我的用词习惯：我喜欢用【列举你的高频词】。
不增加新事实。输出改写稿 + 改动说明（≤5 条）。
```

### P30 · 全文一致性检查

```text
通读全文（粘贴），检查并列表：
1. 术语不一致（同一概念的不同叫法）；
2. 数字前后矛盾（摘要 vs 结果 vs 表格）；
3. 缩写首次出现是否定义、之后是否统一；
4. 图表编号与正文引用是否对得上；
5. 结论是否超出数据支持范围（逐条指出）；
6. 时态/人称是否统一（方法过去时、结论现在时）。
输出问题清单：位置 | 问题 | 建议改法。
```
