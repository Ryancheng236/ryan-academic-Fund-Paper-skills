# 博士开题：研究背景与意义

只在用户写博士开题或博士论文的“研究背景与意义”，或明确要求按博士标准写这一节时使用。背景和意义如何分层，以 references/background-significance.md 为准；本文件的三关更严，不把“前人没研究过”当成意义。硕士开题、课程论文，以及没说明学位层次的开题，仍用 proposal.md 的 P6。不要把这一节写成“宏观背景、缩小领域、引出问题”的八个引言模板；那种开头只说明怎么起句，证明不了这个缺口卡住了领域、值得做三到四年。

这一节要过三关，写完用这三关验收：

1. 问题真实存在：有现象、数据或文献，不是“我觉得有意思”。
2. 缺口是卡住了，不是没人做。没人做是减分项；现有路线做不了或做偏了才是加分项。
3. 意义配得上博士体量。应用验证不够，要有理论或方法上的推进。

默认只写理工版，并按 stem-domains.md 落到仪器、光电或计算机的指标、条件和边界。用户没明确要求时，不写人文社科版，也不做两版对照。学校模板的字数优先；没有模板时，背景与意义合计按 2500 字掌握。文献只写【ref】或用户清单里的 [n]，不编作者和年份。拿不准标【待核】。

按用户要的那一步做，不要七步一次做完。

| 用户要什么 | 做哪条 | 然后 |
|---|---|---|
| 还没给素材，或说先问 | 1 | 问完即停 |
| 要结构，不要正文 | 2 | 给段落任务书后停 |
| 写研究背景 | 3 | 只写背景 |
| 写研究意义 | 4 | 只写意义 |
| 要人文社科版或两版差异 | 5 | 默认任务不做这一条 |
| 审已写的这一节 | 6 | 只挑刺，不重写 |
| 综述味太重，改成论证 | 7 | 不新增事实 |

素材已经够写用户点名的那一步时，直接写，不要为了条目里的“先问再动笔”退回去。缺的槽标【待补】。

## 1. 先问，不写

```text
先不要写正文。围绕我的博士论文题目《【题目】》，只就“研究背景与意义”这一节，问我 8 个必须回答的问题，按重要性排序，每个问题说明“答案会怎样改变这一节的写法”。

必须覆盖：该领域近五年公认的进展、已知的反常或失效案例、谁在关心这个问题（学界/产业/政策，理工课题再加工程应用）、如果不解决五年后会怎样、我的前期工作处在哪一步。

我回答后你再动笔。
```

## 2. 段落任务书

```text
不要写正文。给我一份“研究背景与意义”的段落任务书，总字数【2500】，分 5 段。每段列出：段首句（写成完整句子）、这一段要完成的论证任务、需要哪类证据或文献、建议字数。

硬约束：5 段连起来必须回答三个问题——为什么这个问题存在、为什么现在必须解决、为什么由我来做。如果某一段删掉后这三个问题仍成立，标出来，我砍掉它。
```

段首句必须是论点句，不能是“随着……的发展”。证据类型按专业落：仪器写测量条件与误差，光电写光学边界，计算机写任务设定与基线。没有用户数据时，证据栏写【待补】，不要编。

## 3. 把综述写成论证

```text
你是【学科】方向的博士开题评审专家。素材如下：
研究现象：【】
现有解释或做法：【】
我注意到的矛盾/反常：【】
我的研究问题：【】

请写“研究背景”，要求是论证，不是文献综述：
段1（200字）：用一个具体事实、数据或案例开篇，最后一句点出“为什么这件事现在必须回答”。
段2（450字）：已有研究做到哪一步——按 2-3 条路线，每条按“代表做法→解决了什么→付出了什么代价/边界在哪”写。
段3（450字）：这些路线共同回避或解释不了什么。要说明它是“卡住了”，不是“还没人做”。
段4（200字）：我的问题如何从这个缺口里长出来，一句话收住。

规则：每段首句是论点句；不出现“随着……的发展”“具有重要的理论意义”；文献位置一律写【ref】，不要编造作者和年份；拿不准的地方标【待核】。
```

路线只能来自用户给的做法。用户没给代表工作时，写路线类型并标【待补文献】，不要补作者。

## 4. 意义要经得起“所以呢”

```text
写“研究意义”，分三层，每层 150-200 字：
1. 理论意义：对哪个理论、概念或机制构成修正、补充还是挑战？说清“修正了什么、往哪个方向修正”。
2. 方法意义：提供了什么新工具、新数据或新设计？谁可以直接复用、复用在什么场景？
3. 实践意义：谁会用、用来做什么决定、可能改变什么？必须给一个具体场景，不要给一个群体名词。

写完后，对每条意义追问一次“所以呢？”，把追问出来的那一层补进去，删掉被追问穿的句子。

禁止：“具有重要的理论意义和实践价值”“为……提供参考”“填补了空白”。
```

仪器、光电、计算机的理论意义必须落到机制、误差关系、成像模型或算法假设，不能只写“提升了精度”。没有量化对照或适用边界时，方法意义和实践意义标【待补】，不要写“性能大幅提升”。

## 5. 两版改写：默认不做

只有用户明确要求人文社科版，或要求两版对照时，才执行下面这条。否则只保留理工版，并按 stem-domains.md 写指标、条件和边界。

```text
把上面写好的“背景与意义”改写成【人文社科 / 理工医】版本：
- 人文社科版：以理论争论或现实问题切入，突出概念界定与解释框架的冲突，意义落在“对既有解释的修正”和“对政策/实践的启示”，允许出现田野、文本、案例。
- 理工医版：以技术瓶颈或工程需求切入，突出指标、条件、适用边界，意义落在“机制揭示”“方法可用性”“性能提升幅度”，必须给量化对照。

输出改写稿，并列出两版在“证据类型、论证顺序、意义落点”上的差异表。
```

量化对照只用用户给的数字。没有数字就写“幅度【待补】”，不要配一个示例百分比。

## 6. 写完自检

```text
以博士开题评审专家身份审我这段“研究背景与意义”（粘贴）：
1. 用一句话说出你认为我的研究问题是什么——如果说不出来，说明我没写清；
2. 统计“背景铺陈”与“问题论证”的字数比，超过 2:1 就提示我；
3. 找出 3 句“正确但无用”的话（换个题目也成立的句子），逐句引用；
4. 找出 2 处“意义悬空”（结论大于证据）；
5. 提 3 个答辩最可能被追问的问题，并判断我现在的文本能否回答。
```

只出问题和判断，不重写。

## 7. 去掉综述味

```text
把下面这段“综述式背景”改成“论证式背景”，只做四件事：
1. 把“XX 研究表明……”“XX 发现……”的并列堆叠，改成“关于 X，存在两种对立解释：……”；
2. 每处引用后补一句“这对我意味着什么”；
3. 把“尚未见报道”改成“现有工作在【条件】下失效，因为……”；
4. 段尾加一句指向我研究问题的过渡。
保留我的文献和数据，不新增任何事实。
```

如果原文没有对立解释或失效条件，不要编。改成“这里需要两种做法的代价对比，素材不足”并停在该句。

## 三个最常见的失分点

| 症状 | 表现 | 改法 |
|---|---|---|
| 综述化 | 三段都在说“谁做了什么”，没有一句是“所以卡在哪” | 用第 3 条的“代价/边界”句式，每条路线必须以局限收尾 |
| 意义悬空 | “为 XX 提供理论依据”，但全文没有任何理论、模型或误差关系被修正 | 用第 4 条的“所以呢”追问，问穿就删 |
| 头重脚轻 | 背景很长，研究问题只有一两句 | 背景与问题控制在 2:1 以内，问题单独成段 |
