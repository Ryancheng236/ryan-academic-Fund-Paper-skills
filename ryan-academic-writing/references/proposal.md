# 选题与开题报告

整份开题且目录未确认时，只做 P5，然后停。点名某一节时只做对应条目。P12 和 P13 只出大纲、追问或体检清单，不重写正文。文末“八节覆盖清单”只用来核对槽位和拦截空模板，不代替上面的 P 条。 动笔前按 references/stem-domains.md 判断是仪器、光电还是计算机，只使用对得上的那一节。

## 3. 选题与开题报告

### P1 · 选题收敛（从"方向"到"能做完的题"）

```text
我的方向是【】。请用"现象—矛盾—空白—问题"四步帮我收敛，每步都要具体：

1. 现象：这个领域目前公认的 3 个重要现象或事实（只写你有把握的，标注置信度高中低）。
2. 矛盾：现有解释或方法在哪里互相打架、或解释不了哪类观测。
3. 空白：由此产生的空白，分成理论空白 / 方法空白 / 数据空白 / 应用空白，各举 1 例。
4. 问题：给出 5 个可操作的研究问题，每个一句话，必须含"研究对象 + 关键变量或机制 + 边界条件"。

然后对 5 个问题打分（1-5）：三年内可完成性、数据可得性、创新度、被同行抢先的风险、与我现有基础的匹配度。
最后推荐 1 个，并明确说明"为什么不选另外 4 个"。
```

### P2 · 研究问题拆解

```text
我的总目标是【】。请把它拆成 3-4 个子问题，要求：
- 每个子问题对应一个可交付的结果（论文/模型/数据集/结论），写出来；
- 子问题之间是递进关系，不是并列清单，请说明"前一个的结论如何成为后一个的输入"；
- 每个子问题给出 1 个可证伪的预期或假设；
- 标出哪个子问题失败会导致整个课题无法成立（关键路径）。
用表格输出。
```

### P3 · 文献矩阵（喂料式，防幻觉）

```text
我不需要你替我找文献。以下是我读过的文献要点（逐条粘贴：作者年份 / 研究问题 / 方法 / 样本或数据 / 核心结论 / 作者自述局限）。

请：
1. 按"学术争论"把它们组织成 3-5 个阵营，而不是按时间或作者罗列；
2. 输出对照表：文献 | 阵营 | 问题 | 方法 | 数据 | 结论 | 局限 | 与我的关系（支持/冲突/互补）；
3. 指出每个阵营的共同假设是什么，谁的证据更强，强在哪；
4. 找出所有文献共同没做的事，并判断这是"没人想到"还是"客观上做不了"；
5. 用 300 字写一段评述：先肯定进展，再指出分歧，最后落到我的问题上。

禁止添加清单之外的任何文献。
```

### P4 · 识别真正的 gap

```text
基于上面的文献矩阵，给出 5 个候选研究空白，并逐个"压力测试"：
- 它是真空白，还是只是没人用某种方法做过（后者是集成，不是空白）？
- 如果它重要，为什么这几年没人做？（数据难得 / 技术不成熟 / 结论已隐含在别的文献里 / 其实做过了）
- 需要什么关键证据才能填补？
- 如果我现在做，最可能被审稿人用什么理由拒？
最后只保留 2 个能站住的，并给出对应的"一句话立项理由"。
```

### P5 · 开题报告目录设计

```text
我是【学校/学院】的【硕士/博士】研究生，题目暂定《【】》，学院模板要求如下：【粘贴模板结构或字数要求】。

第一步只做目录，不写正文。按模板逐节给出：
- 这一节要回答的核心问题（一句话）；
- 评委/导师最想看什么；
- 最常见的失分点；
- 建议字数；
- 我需要提前准备哪些材料（数据、图、文献）。

第二步：检查各节之间是否存在"研究内容—研究方法—预期成果"对不上的地方，列出来。
等我确认目录后，再逐节写正文。
```

### P6 · 研究背景与意义

硕士开题，或用户没说明是博士时，用下面这条。背景和意义的分层按 references/background-significance.md。博士开题的这一节改读 references/phd-background.md，不使用这 800 字四段。

```text
写开题报告的"研究背景与意义"，800 字，四段：
段1（150字）：从一个具体的现实问题或反常现象切入，不要用"随着……的快速发展"开头。
段2（250字）：这个问题为什么现在必须解决——政策、产业、健康、安全任一维度，用我提供的数据【粘贴数据】；我没给的数据标【待补】。
段3（250字）：现有做法做到哪一步、卡在哪，引出本研究的位置。
段4（150字）：理论意义 + 实践意义各一句，必须具体到"为谁解决什么"，禁止"具有重要的理论意义和现实意义"。

要求：每段第一句是论点句；全文不出现"填补空白""国际领先""首次"。
```

### P7 · 国内外研究现状（CARS 中文版）

```text
按 Swales CARS 模型写"国内外研究现状"，1500 字，四层：
1. 确立领域：该问题在【学科】中的位置，近 5 年为何升温（只写趋势，不写具体文献）。
2. 划分阵营：把已有工作分成 3 条路线，每条路线 1 段，结构为"代表做法 → 解决了什么 → 代价是什么"。
3. 指出缺口：用"然而/但是"转折，落到 2 个具体缺口，每个缺口要能被我的研究内容直接对应。
4. 占据位置：一句话说明本研究如何补这两个缺口（不展开方法）。

规则：每段一个论点；路线之间要有比较，不能各说各话；引用处写成【作者, 年份】占位，由我后补真实文献。
```

### P8 · 研究内容、重点与难点

```text
基于我的题目《【】》和上面确定的研究问题，写"研究内容"，要求：
1. 总起段：一句话说清整个课题在做什么，100 字以内；
2. 分 3 个研究内容，每块 250 字，内部按"要解决什么 → 具体做什么 → 产出什么"组织；
3. 三块之间必须是递进（内容2 用内容1 的结果），并显式写出衔接句；
4. 单列"研究重点"2 条、"研究难点"2 条，难点必须写出"难在哪、我打算怎么绕过去"。

禁止把研究内容写成方法罗列或时间计划。
```

### P9 · 研究方法与技术路线

```text
为上述 3 个研究内容设计研究方法与技术路线：
1. 每个研究内容配 1-2 个方法，写清：方法名、输入、关键步骤、输出、为什么这个方法适合这个问题（而不是"该方法被广泛使用"）。
2. 给出技术路线文字描述：从数据/样本 → 处理 → 分析/建模 → 验证 → 结论，每一步标注对应研究内容编号。
3. 用 Mermaid 画流程图（flowchart TD），节点不超过 20 个，关键判断用菱形。
4. 列出 3 个可能失败的技术环节和备选方案。
形式：先文字，后代码块。
```

### P10 · 创新点

```text
从我的研究内容中提炼 3 条创新点，每条 120 字，严格按四要素写：
【类型：理论/方法/视角/数据/集成】+【现有做法及其局限】+【我的做法及为何能突破】+【突破后的意义】。
要求：每条注明对应的研究内容编号；删掉所有形容词；"首次将 A 用于 B"这类表述必须补充"为什么这个迁移不平凡"。
```

### P11 · 进度安排与预期成果

```text
按【3 年/2 年】制定进度表，按学期或季度分 6-8 个阶段，表头：时间 | 任务 | 对应研究内容 | 里程碑成果 | 风险。
要求：文献调研不超过总时长的 1/5；预留 3 个月用于补实验和写作；每个阶段都有可检查的产出物。
另附预期成果：论文【】篇（注明目标期刊层次）、专利/软著【】、数据集/模型【】、毕业要求如何对应。
```

### P12 · 开题答辩：PPT 与追问预演

```text
我要做开题答辩，15 分钟。请：
1. 给出 12 页 PPT 大纲，每页：标题 + 3 个要点 + 建议配图类型 + 讲述时长；
2. 扮演 5 位评委（2 位小同行、1 位方法学专家、1 位跨学科、1 位严格管进度的），各提 3 个最可能问的问题，按"杀伤力"排序；
3. 对最狠的 5 个问题，给出 3 句话以内的回答要点（先承认边界，再给方案，最后给时间点）。
```

### P13 · 开题报告整体体检

```text
通读我的开题报告（粘贴全文），按下面清单逐项打勾或打叉，并给出修改建议（每条不超过 2 句）：
□ 题目是否指向一个具体问题，而非一个领域
□ 研究问题是否只有 1 个主线，而不是 4 个并列方向
□ 研究内容、方法、预期成果是否一一对应（列出对应表）
□ 每个创新点是否有"现状—差异"的对比
□ 技术路线是否能看出先后依赖
□ 进度安排是否与工作量匹配
□ 参考文献近 5 年占比是否 ≥ 50%
□ 全文是否存在"具有重要意义"类空话（统计出现次数）
最后给一个总体判断：可以开题 / 小修后开题 / 需重写某节。
```


## 八节覆盖清单

用户没有学院模板，或要求按“研究背景、研究现状、研究问题、方法、创新、进度、难点、目标”写研究计划或开题时，用这份清单核对要填的槽。它不代替 P5-P13。点名某一节就只写那一节。学校模板的章节名和字数优先。

下面是空模板原文。它只标明每节有哪些槽。禁止把这些原句写进正文，尤其不要输出“随着……的快速发展”“具有重要的现实意义”“填补这一空白”“大量研究”“推动某领域的发展”。用户草稿如果就是这段，或只是把方括号换成了同样空的词，按对应 P 条重写，不要在原句上润色。

```text
1. 研究背景与意义

本研究旨在探讨 [研究主题]，通过分析当前[领域或问题]的现状，揭示其中存在的[挑战/机遇]。随着[某种技术/现象]的快速发展，针对[具体问题]的研究越来越重要，该课题的研究背景包括 [相关背景]。

本课题具有重要的现实意义，因为它可以帮助解决[某个具体社会或经济问题]，推动[某领域的进步]，同时填补学术界在[研究空白]中的不足。

2. 研究现状与文献综述

目前国内外关于该主题的研究现状表明，已有大量研究关注了[领域A]和[领域B]，例如，[相关作者]提出了[重要理论或结论]，然而，仍存在[未解决的问题]。

通过对相关文献的分析，我们发现大部分现有研究集中于[特定方向]，但关于[另一个方向]的探讨较为有限，因此本研究将着眼于[填补这一空白]。

研究空白主要集中在[问题1]和[问题2]，这些问题的深入研究有助于推进[某个领域]的发展。

3. 研究问题与假设

本研究的主要问题是如何[核心问题]，以及[相关问题]的影响因素是什么。

研究的核心问题可以概括为 [核心研究问题]，包括[子问题1]、[子问题2]和[子问题3]。

本研究假设 [具体假设]，例如，[假设1：某变量对另一变量有显著影响]。

我们期望通过[某种方法]来验证以下假设，并得出[预期结论]。

4. 研究方法与设计

本研究将采用定量/定性研究方法，具体包括[研究方法1]和[研究方法2]，以收集相关数据。

该研究的主要方法为[实验法/问卷调查/访谈]等，研究对象将从[某个群体]中选取，样本量为[具体数字]。

本研究采用的实验设计是[具体设计]，以确保数据的可靠性和有效性。

数据分析将通过XXX软件进行，使用[具体统计或分析方法]来验证研究假设。

5. 研究创新与贡献

本研究的创新点在于 [创新点1] 和 [创新点2]，这些创新点与现有研究相比，具有[哪些不同或改进]。

本研究试图从[某个新视角]切入，相较于已有文献的不同之处是[具体创新]，希望为[某领域]带来新的理论贡献或应用价值。

本研究将对该领域带来以下贡献，不仅扩展了[理论基础]，还提供了[某种实际应用]的参考。

6. 研究计划与进度安排

预计研究分为以下几个阶段：

1. 第一阶段（[时间范围]）：[文献收集与综述]。
2. 第二阶段（[时间范围]）：[研究设计与数据收集]。
3. 第三阶段（[时间范围]）：[数据分析与结果讨论]。
4. 第四阶段（[时间范围]）：[撰写与修改论文]。

研究计划的时间安排为[具体时间表]，确保在[特定时间]内完成所有任务。

7. 研究难点与可行性

该研究的主要难点在于 [技术/理论上的困难]，例如，数据的获取可能受到[某些限制]，但可以通过[解决方案]克服。

我们预期的技术/理论难点是[难点1]和[难点2]，这些挑战将通过[具体措施]来应对。

本研究具有可行性，因为 [资源充足/已有初步数据/研究方法成熟]，并且研究团队具备[相关经验]。

8. 研究目标与成果

研究的最终目标是提出一套[理论框架 /解决方案]，以帮助[解决某问题]，推动[某领域的]发展。

本研究旨在获得的结论为 [具体结论]，这些结论将验证或推翻之前的研究假设，并为[某领域]提供新的见解。

研究的预期成果将包括[学术论文 /研究报告]，同时希望为[行业/政策]的实际应用提供依据。
```

写的时候按槽填用户材料，对不上的标【待补】：

| 节 | 必须填的槽 | 用哪条 | 不要写成 |
|---|---|---|---|
| 研究背景与意义 | 具体现象或问题、为何现在要做、为谁解决什么 | P6 | 随着快速发展；重要现实意义；填补空白 |
| 研究现状与文献综述 | 只用用户给的文献；按争论分阵营；缺口能对应到研究内容 | P3、P4、P7 | 大量研究；用户没给作者时写“某作者提出了某理论” |
| 研究问题与假设 | 一个主问题；子问题递进；假设可证伪，且用户提供了依据 | P2 | 没填实的“如何[核心问题]”；没有依据就写“显著影响” |
| 研究方法与设计 | 方法名、对象、样本量、设计、软件和分析方法；数字只来自用户 | P9 | 定量/定性都不落；XXX软件 |
| 研究创新与贡献 | 每条含类型、现有做法及局限、自己的做法、为何不平凡 | P10 | 新视角、理论贡献、应用价值等空形容词 |
| 研究计划与进度安排 | 时间、任务、对应内容、可检查产出、风险 | P11 | 四个阶段各写一个动名词就算完成 |
| 研究难点与可行性 | 难在哪、怎么绕；可行性每条要有证据 | P8 的难点；证据不够就标【待补】 | 只写资源充足、团队有经验 |
| 研究目标与成果 | 做了什么、得到什么可检查成果；未做的实验不写成已发现的结论 | P11 | 把预期结论写成已经发现的事实 |
